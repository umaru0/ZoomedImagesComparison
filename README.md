# Zoomed Images Comparison

Инструмент для сравнения изображений с функцией увеличения.

## 🌐 Демо

- **Стабильная версия (main)**: https://umaru0.github.io/ZoomedImagesComparison/
- **Dev версия (разработка)**: https://umaru0.github.io/ZoomedImagesComparison/dev/

## 🚀 Функции

- Drag & Drop загрузка изображений
- Синхронизированный зум между двумя изображениями
- Регулировка масштаба колесиком мыши
- Отображение информации о файлах

## 💻 Разработка

- `main` - стабильная версия
- `dev` - версия для разработки и тестирования новых функций
